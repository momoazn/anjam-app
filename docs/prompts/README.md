# AI/Agent Prompts

This directory contains prompts designed to guide AI agents in implementing specific features or transformations.

## Available Prompts

### [Linear UI/UX Transformation Prompt](./linear-ui-ux-prompt.md)

**Purpose**: Guide AI agents in transforming Anjam's Product Mode UI to align with Linear's design system.

**Use Case**: When implementing or updating Product Mode features, use this prompt to ensure consistency with Linear's "Tactile Minimalist" framework.

**Content**:

- Visual identity and theming guidelines
- Layering and elevation system
- Typography and information density rules
- Border and glow techniques
- Keyboard-first workflow instructions

**References**:

- [Linear Design Analysis](../product/linear.md) - Deep analysis of Linear's design system

## Creating New Prompts

When creating a new prompt for AI agents:

1. **Purpose**: Clearly state what the prompt is for
2. **Context**: Provide necessary background and context
3. **Instructions**: Give specific, actionable instructions
4. **References**: Link to relevant documentation for deeper understanding
5. **Examples**: Include before/after examples when helpful

After creating a prompt, add it to this README with:

- File name
- Purpose

- Brief content summary
